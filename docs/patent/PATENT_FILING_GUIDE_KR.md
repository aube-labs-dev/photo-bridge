## 2. 선행기술 조사 (본인 수행)
### KIPRIS (kipris.or.kr) — 권위 있는 국내 검색
추천 검색어 조합:
- `WebRTC AND 파일 전송 AND 브라우저`
- `P2P AND 사진 전송 AND 서버 미경유` / `피어투피어 AND 데이터채널`
- `시그널링 AND 파일 공유` / `브라우저 간 전송`

### Google Patents (patents.google.com) — 영문 선행
- `WebRTC browser file transfer signaling server-less`
- `peer to peer photo sharing without account`

### 차별화 포인트(청구항 방어 논리)
| 종래 | 본 발명 |
|---|---|
| 메신저·클라우드 = 사진이 서버에 업로드/저장 | **파일 서버 미경유**(P2P DataChannel 직송) |
| 제조사 전용 근거리 공유 = 동일 OS 진영만 | **OS·기종 무관**(브라우저 표준만) |
| 계정 가입·로그인 필요 | **무가입·무인증**(임시 방 식별자만) |
| 모바일 백그라운드 전환 시 연결 유실 | **재접속키 기반 좀비소켓 치환**(복귀 복구) |
| 전송계층 버퍼 제어만 | **수신측 주도 애플리케이션 계층 흐름제어**(파일 경계 pause/resume) + 전송계층 역압 병행 |
| 사용 분석 위해 행동/식별정보 수집 | **익명 집계**(사건 종류별 총 횟수만) |

> 핵심: 암호화 알고리즘 자체가 아니라 **"서버 무경유 P2P + 무가입 + 좀비소켓 치환 + 애플리케이션 계층 흐름제어 + 익명집계"의 결합**을 청구 → 단일 요소 선행이 있어도 조합의 신규성·진보성으로 방어.

## 3. 명세서 → KIPO 표준 .docx 변환 (Mac)
전자출원SW(NK-Editor)는 Windows 전용. Mac에서는 **명세서를 KIPO 표준 서식 `.docx`로 변환**해 특허로 웹 업로드로 제출.
- `【...】` 섹션 태그 = bold, 본문 = 보통, 도면 = PDF 별도 첨부(또는 docx 임베드).
- 변환 스크립트/동아시아 폰트 설정은 skill `korean-patent-filing` 의 `references/md-spec-to-kipo-docx.md` 참조.
- 변환 후 docx 스킬의 `docx_validate`/`docx_read`로 검증.
- 발명 명칭 영문 관용어는 `...SYSTEM ... AND METHOD THEREOF` 형태로 이미 기재됨.

## 4. 전자출원 절차 (특허로, patent.go.kr)
1. **특허로 로그인** (공동인증서/금융인증서 또는 휴대폰 본인인증) — **본인만 가능**.
2. **출원서 작성** → 특허 → 국내출원 → 명세서 등 첨부.
   - 출원인 = 박종화(개인, 특허고객번호 4-2026-079029-3)
   - 발명자 = 박종화
   - **공지예외주장 체크** (서비스 이미 공개됨 — 1절 참조) + 증명서류 첨부.
3. **명세서(.docx)** + **도면(PDF/이미지)** 업로드.
4. **수수료 납부**
   - 출원료(전자출원) + (선택) 심사청구료.
   - 💡 **심사청구는 출원일로부터 3년 유예 가능** → 자금 사정에 따라 출원만 먼저 하고 우선일 확보 후 나중에 심사청구 가능.
   - 개인 출원인 **감면 제도**(연령/소상공인 등) 해당 여부 확인 시 수수료 대폭 감면.
5. **제출·접수번호 수령**.

## 5. 출원 후 동반 업데이트 (권장)
Photo Bridge는 이미 서비스 중이므로, 특허 출원과 함께 아래도 정합성 유지:
- **개인정보처리방침**: 서버 미경유·무가입·익명집계 명시(현재 설계와 일치하는지 점검).
- **서비스 고지**: "사진은 서버에 저장되지 않으며 기기 간 직접 전송됩니다" 문구 유지.

## 6. 유의사항
- 에이전트는 **명세서·도면·가이드 준비까지만** 가능. 특허고객번호 인증·전자서명·제출은 **본인만**.
- 명세서 placeholder(【선행기술문헌】 번호)는 **실제 조사 결과로 교체 후 제출**.
- 전자출원 전 **공개 12개월 경과 여부**를 최우선 확인(신규성 상실 리스크).
